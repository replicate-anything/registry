# registry

Study metadata lives in `papers/<folder>.yml` stub files. The catalog and machine-readable index are generated by rendering `index.qmd`, which writes `index.csv` (used by `replicateEverything` and the Shiny app) and `index.html`.

**Folder-backed** and **package-backed** studies keep only a lightweight stub in `papers/`. Materials live in the linked study repository or R package. See [guides/folder-replication.md](guides/folder-replication.md), [guides/package-replication.md](guides/package-replication.md), and `replicateEverything::prepare_folder_paper()` / `add_paper()`.
