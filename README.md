# registry

Study metadata lives in `papers/<folder>/replication.yml`. The catalog and machine-readable index are generated by rendering `index.qmd`, which writes `index.csv` (used by `replicateEverything` and the Shiny app) and `index.html`.

**Package-backed studies** keep only a lightweight stub in `papers/<folder>/`. See [guides/package-replication.md](guides/package-replication.md) and `replicateEverything::add_paper()`.
